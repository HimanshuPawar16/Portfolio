# 🚀 Modern Bento Grid Developer Portfolio

A sleek, responsive, single-file developer portfolio inspired by contemporary design trends. It features a dark mode dynamic interface, frosted-glass morphic cards (Bento Grid layout), and an interactive JavaScript HTML5 canvas background.

## ✨ Features

*   **Bento Grid Architecture:** Clean, asymmetrical card grid optimized for modern high-density screens.
*   **Interactive Particle Background:** High-performance, lightweight HTML5 Canvas physics engine rendering responsive, connected nodes.
*   **Zero-Reload SPA Router:** Smooth, internal client-side navigation framework managing state switches instantaneously between Home, Projects, and About sections.
*   **Cross-Browser Text Gradients:** Clean integration of fallback syntax using `background-clip: text` along with native legacy WebKit prefixes.
*   **Fully Responsive:** Fluid, media-query break-points handling seamless collapse into vertical grid systems on mobile displays.

---

## 🛠️ Built With

*   **HTML5** — Document structure and Semantic layouts.
*   **CSS3** — Custom variable tokens, Glassmorphism filters, Flexbox, and CSS Grids.
*   **JavaScript (ES6)** — Dynamic view routing, fluid state changes, and live background animations.
*   **FontAwesome Icons** — Clean vector-graphic iconography.
